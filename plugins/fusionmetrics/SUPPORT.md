# Fusionmetrics plugin support

Contact **Alex from Fusionmetrics, Founder**, at [alex@fusionmetrics.com](mailto:alex@fusionmetrics.com).

Include the assistant and version, plugin version, setup step, and the error message. Remove credentials, Merchant details, and other private information from any screenshots or logs. Never send a Shopify Partner API token, Shopify Client Secret, OAuth token, or MCP bearer token.

For connection problems, reconnect using the assistant's sign-in flow and select the intended Fusionmetrics Organization. An Organization admin must authorize setup changes. If the assistant reports an interrupted import, ask it to read the current setup status before retrying.

The plugin supports setup for Shopify's official React Router app template. Other frameworks require separate evaluation. Local checks confirm code preparation; a deployed app must receive a real contact before contact capture can be reported as working.
