# Fusionmetrics

Version 0.1.0. Endpoint: https://fusionmetrics.com/api/mcp.

Connect your Fusionmetrics Organization to set up Shopify Partner API revenue imports, inspect setup progress, and retry failed imports. Optionally prepare Merchant contact capture in an app based on Shopify's official React Router template. Credentials are entered in your browser. Setup requests read and write permissions; analytics is a separate connection. Contact capture requires access to your local app repository and separate deployment. A successful local check does not establish live contact receipt. A Fusionmetrics account, Organization administrator access for setup writes, and an eligible service plan are required.

Start with: “Set up this Shopify app with Fusionmetrics.” or invoke the setup skill. Sign in through the assistant's browser authorization flow and select the intended Organization. Enter Partner API tokens and Shopify Client Secrets only in Fusionmetrics' browser form, never in chat or committed files.

This package contains manifests, one setup skill, and artwork. It has no hooks, bundled executable server, or API keys. It does not grant analytics access or deploy application changes.

This is a publication candidate; no directory listing is claimed. See the repository's publication checklist for installation testing and review status. After directory publication, installation and browser sign-in can be completed from the assistant's plugin UI.
